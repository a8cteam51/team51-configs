# team51-configs

> [!IMPORTANT]
> **Deprecated.** This repository is frozen and takes no further changes. Its successor is [a8csp-configs](https://github.com/a8cteam51/a8csp-configs).

Projects that already require `a8cteam51/team51-configs` keep working. The repository stays available read-only, and `composer update` still brings in upstream releases of the tools it requires, within the version ranges it declares.

To move a project to a8csp-configs, follow [Migrating from team51-configs](https://github.com/a8cteam51/a8csp-configs/blob/trunk/docs/migrating-from-team51-configs.md).
